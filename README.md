# <span style="color: #4CAF50;">StealthChat</span>

StealthChat is a Python-based WhatsApp messaging agent built with Twilio's API. The project enables automated WhatsApp messaging to a specified number from a sandbox environment with a customizable sender name and message content.

## Features

- 🚀 Send WhatsApp messages from a sandbox number.
- 📝 Customizable sender name (e.g., "Your Beautiful Wife").
- 💬 Message content can be easily modified.
- 🛠️ Uses Twilio API for sending messages.

## Prerequisites

- 🔑 Python 3.6 or higher
- 📝 Twilio Account (Create [Twilio account here](https://www.twilio.com/))
- 🛠️ Twilio Sandbox setup for WhatsApp
- 🔐 `.env` file to securely store Twilio credentials
